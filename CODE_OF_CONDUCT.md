# Code of conduct

This repository follows the Contributor Covenant Code of Conduct (version 2.1):
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

Be respectful, assume good faith, and keep discussion technical. Report unacceptable behaviour to
the maintainer (Gregory Paradis). The maintainer may remove comments, commits, or contributions
that violate the code.
