\section*{Data availability}
The case-study scenarios are available from Zenodo \citep{jaffray2026zenodo}. FHOPS~1.0.1 is
open-source software (MIT licence) available from the Python Package Index and GitHub
\citep{fhops2026v101}. The experiment code (the rolling-horizon runner and the probe and
calibration scripts) and all run outputs (per-run JSON summaries, stitched assignment tables,
solver logs, and summary tables) are openly available in the GitHub repository
\url{https://github.com/UBC-FRESH/jaffray-masc-fhops-model} and archived on Zenodo
\citep{jaffray2026rerun}. The scripts that generate every figure, table, and number in this article
are in \url{https://github.com/UBC-FRESH/fhops-cjfr-rolling-horizon}.
The MIP results were obtained with the commercial Gurobi solver (free academic licences are
available). The SA results and the FHOPS playback evaluation need only open-source software.
