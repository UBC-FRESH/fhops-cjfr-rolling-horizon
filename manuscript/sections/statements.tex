\section*{Data availability}
The primary data supporting the findings of this study are the nine semi-synthetic case-study
scenarios and the complete set of rolling-horizon run outputs (per-run JSON summaries, stitched
machine-assignment tables, solver logs and summary tables). They are openly available in Zenodo,
without restriction and without registration: scenario bundles, doi:10.5281/zenodo.19200385
(\url{https://doi.org/10.5281/zenodo.19200385}, CC BY 4.0); experiment code and all run outputs,
doi:10.5281/zenodo.23626401 (\url{https://doi.org/10.5281/zenodo.23626401}, CC BY 4.0), with a
development copy at \url{https://github.com/UBC-FRESH/jaffray-masc-fhops-model}; analysis code that
regenerates every figure, table and number, doi:10.5281/zenodo.23626443
(\url{https://doi.org/10.5281/zenodo.23626443}, MIT licence), with a development copy at
\url{https://github.com/UBC-FRESH/fhops-cjfr-rolling-horizon}. FHOPS~1.0.1, the open-source planning
system used to run the experiments, is available under the MIT licence from the Python Package Index
and \url{https://github.com/UBC-FRESH/fhops}, and archived at doi:10.5281/zenodo.23244315. No data
were withheld.
The MIP results were obtained with the commercial Gurobi solver (free academic licences are
available). The SA results and the FHOPS playback evaluation need only open-source software.
