# Notes

Notes are the persistent context for this repository. They hold what a reader, human or agent,
needs and cannot get from the code, the issues, or the changelog alone.

- `notes/adr/NNNN-slug.md`: decisions. One decision per file. Never rewrite an accepted ADR;
  supersede it with a new one. Start from `adr/0000-template.md`.
- `notes/reference/`: facts with provenance.
- `notes/plans/`: focused plans that are too long for `ROADMAP.md`, linked from their task.
- `notes/analysis/`: the analysis notes, such as the input audit.
- `notes/archive/`: superseded planning surfaces, kept for the record.
- `notes/reports/`: the close-out report for each phase. Start from
  `reports/phase-closeout-template.md`.

Keep private material out of this directory.
